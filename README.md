# 🧮 AI Math Solver using Gemini 1.5 Flash + Streamlit

This project is an interactive **AI-powered Math Problem Solver** built using **Streamlit** and **Google's Gemini 1.5 Flash LLM**. It allows users to enter any math question (algebra, calculus, arithmetic, etc.) and receive detailed step-by-step solutions generated by Gemini.

---

## 🔧 Tech Stack

- Python 3.10+
- Streamlit (for web-based UI)
- Google Gemini 1.5 Flash LLM
- python-dotenv (for API key management)

---

## 🚀 Features

- ✅ Real-time AI-powered math solving
- ✅ Fast responses using Gemini 1.5 Flash
- ✅ Clean and minimal UI using Streamlit
- ✅ Handles arithmetic, algebra, calculus, etc.
- ✅ Secure API key handling via `.env`

setup_instructions:
  - step: Clone the repository
    commands:
      - git clone https://github.com/yourusername/math-solver
      - cd math-solver

  - step: Create and activate virtual environment
    platform: Windows
    commands:
      - python -m venv .venv
      - .venv\Scripts\activate

  - step: Install dependencies
    commands:
      - pip install -r requirements.txt

  - step: Create .env file and add Gemini API key
    instructions:
      - Create a file named `.env` in the project root
      - Add the following line:
    content: |
      GEMINI_API_KEY=your_api_key_here
    note: Get your API key from https://makersuite.google.com/app/apikey

  - step: Run the Streamlit application
    commands:
      - streamlit run mathui.py
